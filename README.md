# Play With Momoo — Quiz Shorts

A reusable 1080×1920 quiz-short starter with matching Remotion and HyperFrames renderers.

## Commands

```bash
npm install
npm run studio
npm run render
npm run hf:preview
npm run hf:render
```

Edit the quiz copy and timing in `src/quiz.ts`. The first voiceover belongs at `public/audio/quiz-01.mp3` and is shared by both renderers.

The starter mascot is intentionally CSS-only. Replace it with the final Momoo artwork once the original brand assets are available.
